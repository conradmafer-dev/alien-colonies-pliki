2. Zainstaluj Android Build Template dla projektu. Skonfiguruj ścieżki
   Android SDK oraz Java JDK 17 w ustawieniach edytora.
3. Uruchom z katalogu projektu:

   python tools/configure_android_build.py

   Narzędzie ustawia zweryfikowane wersje Android SDK/AGP, kopiuje
   tools/preserve_launcher88.gradle do android/build i dołącza go dokładnie
   raz w build.gradle. Drugie wywołanie nie dodaje kolejnej deklaracji.
   Hook zachowuje warstwę monochrome w aktywnej ikonie adaptacyjnej.
4. Wykonaj pełny import zasobów. Eksportuj preset Google Play AAB w trybie
   release. Nie zmieniaj ścieżek ikon ustawionych w export_presets.cfg.
5. Nowy eksport wymaga ponownej walidacji i własnej sumy SHA-256. Dołączony
   PODPISZ88.bat jest przypięty do dokładnego AAB o sumie podanej powyżej;
   nie będzie podpisywał innego pliku pod tą samą nazwą.
