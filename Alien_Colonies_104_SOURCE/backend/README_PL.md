# Alien Colonies — Android 0.11.4

Pełny projekt **Godot/Android 0.11.4, kod 48** z graficznym przygotowaniem
wypraw: wybór układu i planety, portrety bazy i celu, kafelki rodzaju misji,
podsumowanie rzeczywistej wyceny oraz potwierdzenie wysyłki.

**Zacznij od `START_TUTAJ.txt`.** To źródła, nie gotowy APK/AAB.
Samo wdrożenie na Railway nie aktualizuje interfejsu aplikacji Android.

`railway/` zawiera niezmieniony serwer i WWW **0.11.3**. Nowy ekran klienta
nie wymaga jego ponownego wdrożenia ani resetu zapisów.

Bieżące wyniki: `VERIFICATION_0114.json` i `docs/verification_0114/`.
Starsze raporty w `docs/` są historyczne. Scena natywnego testu nowego UI:
`tests/test_fleet_navigation_0114.tscn` (do uruchomienia w Godocie).

Nie wykonano eksportu APK/AAB, testu fizycznego telefonu ani wdrożenia serwera.
